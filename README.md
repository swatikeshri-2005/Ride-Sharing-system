# Ride Sharing System (Uber Model)

A C++ based Ride Sharing System featuring:
- Shortest Path using Dijkstra
- Multiple Cabs
- Ride Pooling
- Dynamic City Graph
- ETA + Fare Calculation

## Features
✔ Graph using adjacency list  
✔ Priority Queue  
✔ Nearest cab assignment  
✔ Ride pooling  
✔ Dynamic city input  

## Tech
Language: C++
Concepts: Graph, Priority Queue, Dijkstra

## Run
g++ main.cpp
./a.out
